# MKT — Trabajo de marketing

Repositorio de marketing (web, redes sociales, contenido y SEO) gestionado por ARA.
**Independiente del repo `ara-health`** (producto/ingeniería) — acá va solo lo comercial.

## Estructura

```
mkt/
├── clientes/
│   └── centro-ojos-lazarte/    ← Clínica oftalmológica, Córdoba
│       ├── web/                ← Sitio web (HTML/CSS/JS, estático)
│       ├── contenido/          ← Planes IG + blog, auditorías
│       └── marca/              ← Línea visual, accesos, datos
├── convenios/                  ← Nuevas negociaciones y acuerdos (uso de Ricky)
└── _plantillas/                ← Recursos reutilizables entre clientes
```

Cada cliente nuevo se agrega como carpeta dentro de `clientes/`.
