# VER PARA VIVIR — Salud Visual Integral para el Adulto Mayor

> Frente: **Municipios + Hogares/Geriátricos** · Cliente: Centro de Ojos Lazarte (Córdoba)
> Lema: *«Que ningún adulto mayor pierda la vista por no llegar a tiempo.»*

Programa permanente de **prevención, diagnóstico precoz y tratamiento** de enfermedades
visuales en adultos mayores (cataratas, glaucoma, DMAE, retinopatías, baja visión),
implementable desde la clínica mediante **convenios con municipios, hogares/geriátricos
y financiadores**. Diseño genérico y replicable a toda Córdoba y luego al país.

## Lo esencial

- **Modelo económico A–E:** A) PAMI (cubre cataratas 100%, monofocal) · B) APROSS · C) otras
  OOSS/prepagas · D) particular · E) **sin cobertura** → precio social + bonificación del Centro
  + **saldo cofinanciado por el municipio** (contra prestación documentada).
- **Regla de oro:** primero se agota la cobertura formal → luego precio social bonificado → el
  municipio/fondo cubre solo el **saldo ya reducido** (nunca el precio total).
- **Marco jurídico:** Ley 27.360 (derechos personas mayores), autonomía municipal (Const. Cba
  art. 180/186/190), Ley Orgánica Municipal 8102, RUGEPRESA. Destinar fondos a salud visual del
  adulto mayor es **cumplimiento de una obligación jurídica**, no una liberalidad.
- **Antecedentes:** ✅ Salta «Libre de Cataratas», ✅ Gral. Alvear (Mendoza), ✅ APROSS Salud Visual.
  ⚠️ Necochea (rechazado): lección → **evitar subsidio nominativo y contraprestación en especie;
  medir estadísticas desde el día uno**.
- **Arquitectura municipal:** Ordenanza que crea el Programa + Convenio específico + Anexos.
